## 🔒 Защита от повторного голосования (Анти-чит)

- **Авторизация через Telegram:** У каждого студента фиксируется уникальный цифровой ID Telegram (`id`), привязанный к аккаунту. Повторная отправка с одного аккаунта физически блокируется сервером.
- **Подтверждение по списку:** Дополнительно каждый голос сверяется со списком студентов, чтобы от имени одного студента нельзя было проголосовать дважды.
- **Тайное голосование:** Публично отображаются только суммарные проценты и список участников явки (кто принял участие). Кто за кого голосовал — скрыто (доступно только организатору в зашифрованном аудит-логе).
- **Праздничные салюты (Конфетти):** Эффектный визуальный отклик при успешном голосовании.

## 💾 Где хранятся голоса?

1. **Локально (для разработки и тестов):**
   - Автоматически работает без базы данных прямо «из коробки» (in-memory + файл кэша `.votes_cache.json`).
2. **В продакшене на Vercel:**
   - **Upstash Redis (Vercel KV)** — идеальная бесплатная serverless NoSQL база данных:
     - 10 000 бесплатных запросов в день (хватит на тысячи голосований).
     - Мгновенные атомарные проверки `sismember` / `hincrby` исключают состояние гонки (race conditions).
     - Подключается в панели Vercel в 1 клик во вкладке **Storage → KV / Redis**.

## ☁️ Деплой на Vercel (Инструкция по шагам)

### Способ 1: Через GitHub (Самый простой)
1. Загрузите папку с проектом в свой репозиторий на GitHub.
2. Откройте [vercel.com](https://vercel.com) и нажмите **"Add New..." → "Project"**.
3. Выберите ваш репозиторий.
4. В разделе **Storage** добавьте **Upstash Redis** (или создайте бесплатную базу на [upstash.com](https://console.upstash.com)).
5. Заполните переменные окружения (**Environment Variables**):
   - `UPSTASH_REDIS_REST_URL`
   - `UPSTASH_REDIS_REST_TOKEN`
   - `ADMIN_PASSWORD` (например, ваш секретный пароль)
   - `TELEGRAM_BOT_TOKEN` (токен вашего бота)
6. Нажмите **Deploy**! Через 45 секунд ваш сайт будет доступен всему потоку по красивой ссылке `.vercel.app`.

### Способ 2: Через Vercel CLI из консоли
```bash
npx vercel
```

## 🤖 Как настроить Telegram Бота (1 минута)

1. Откройте Telegram и найдите официального бота **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду `/newbot`.
3. Задайте имя (например: `Выборы Старосты`) и юзернейм (например: `group_elections_bot`).
4. Скопируйте полученный **HTTP API Token** (вида `712345678:AAH...`) и вставьте в `TELEGRAM_BOT_TOKEN`.
5. Отправьте команду `/setdomain` боту @BotFather и укажите домен вашего сайта на Vercel (например: `my-vibori.vercel.app`), чтобы Telegram разрешил вход.
